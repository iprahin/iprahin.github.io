# Igor Priakhin — portfolio website

Static bilingual portfolio website for GitHub Pages.

## Files

- `index.html` — Russian version
- `en.html` — English version
- `styles.css` — responsive paper-light design
- `script.js` — screenshot gallery
- `assets/` — portrait and project screenshots
- `.nojekyll` — disables Jekyll processing on GitHub Pages

## SEO checklist before publishing

https://iprahin.github.io/

After you know the final GitHub Pages URL or custom domain, update these in both `index.html` and `en.html`:

1. Add an absolute canonical URL.
2. Replace relative `hreflang` links with absolute URLs.
3. Add the final URL to the JSON-LD `url` field.
4. Optionally add `sitemap.xml` with the final absolute URLs.

No email is shown on the website. Contact is via LinkedIn only.
